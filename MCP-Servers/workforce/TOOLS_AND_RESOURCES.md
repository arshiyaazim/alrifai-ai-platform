# Workforce Tools and Resources

Employee resources expose the authoritative normalized Employee ID only within trusted authorization scope. Current contact numbers, historical Employee IDs, and internal technical references are distinct fields; no contact observation performs an Employee-ID edit.

Proposed tools: `resolve_employee`, `get_employee_profile`, `create_employee_from_approved_joining`, `update_employee_status`, `record_assignment`, `record_attendance`, `list_attendance`, `get_workforce_history`, `list_employee_aliases`.

Resources: employee profile/lifecycle, normalized contact identities, attendance history, operational assignment history, review queue. `get_employee_financial_ledger` is a Finance query, not a Workforce write.
