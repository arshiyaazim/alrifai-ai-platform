# Platform and Admin Tools and Resources

Proposed tools: `get_cross_domain_report`, `get_approval_queue`, `approve_draft`, `reject_draft`, `get_audit_trail`, `get_provenance`, `get_workflow_status`, `orchestrate_approved_action`, `get_domain_health`.

Resources: audit event, business event, provenance record, approval item, cross-domain report, workflow correlation, health/status view. `orchestrate_approved_action` may call domain services but cannot write domain tables itself.
